Typography

Families: Google Sans (display, headline, title-large, panel headers; only 400 loaded), Google Sans Text (everything else; 400/500 loaded, 600/700 synthesised), Google Sans Code (inline code), Google Symbols (icons, ligatures, font-feature-settings: "liga"), KaTeX (math). No other font-feature-settings or variation axes are set; the type scale is Material 3 with Google's font swap. Tracking 0.006rem (0.096px) on small text.

Spacing, sizes and layout

{{SPACING}}

Grid. Home: content column starts at 60px from the viewport edge at 1200px (table 1068px wide). Grid cards are 320×224 in auto-fill columns with ~41px gutters and ~16px row gaps. Workspace: three panels with a 16px gutter and 16px outer margin; side panels 289.8px at a 1200px viewport, chat takes the rest (max message width 700px). Opening a Studio artifact widens Studio to 450px.

Header. 64px (96px on mobile, two rows). Panel header 48px + 1px rule. Rows. Table header 56, table row 52, menu item 48, list option 48, source row 32, artifact row 64, Studio tile 56.

Mobile (<600px). Panels collapse into three tabs (Sources / Chat / Studio), header gets a second row, chat box padding drops from 16 to 12, home list view forced with 20px side padding, section toggle scrolls sideways.
