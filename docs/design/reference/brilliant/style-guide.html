Brilliant design reference

Every value on this page is a CSS variable generated from tokens.json. The tokens were read from brilliant.org on 2026-09-25 (Panda CSS custom properties, text-style rules and computed styles). The product has two themes, light and dark; use the switch at the top right. Hover the swatches for their source.

Palette

14 hues with 11 steps (50 to 950, yellow adds 850) plus white and black alpha ramps. The palette itself does not change between themes; the semantic roles below do.

Semantic colour

Roles as Panda names them. Each swatch shows the value for the current theme.

Gradients

Typography

Two proprietary families: CoFo Brilliant (sans, 400/500/700) for everything in the UI and CoFo Robert (serif, 500) for display headlines. CoFo Semi Mono sets interactive tiles, Source Code Pro code, KaTeX maths. No font-feature-settings are applied. These 33 styles are the product's own textStyles.

Spacing, sizes and breakpoints

A 4px scale (Panda defaults, rem based). The layout switches at lg = 769px; content is 432px wide below it and 1216px above.

Layout and component sizes

Breakpoints and z-index

Radius and borders

Brilliant's default border is 2px. Hairlines (0.5px) are used on chat bubbles and glass buttons.

Elevation

Shadows are soft and centred (no y-offset) for floating surfaces, and hard 4px lips for anything that should look pressable.

Motion

No duration tokens exist in the product (its fast/normal classes compile to invalid CSS), so these are the durations actually used. Press a row to play it.
