ResearchRabbit, measured

Every value on this page is a CSS variable generated from tokens.json, which was read from app.researchrabbit.ai on 2026-10-04: the app's own :root variables, literals from its styled-component rules, and the constants of its graph engine (the Litmaps map engine, read from the bundle; see raw/graph-code-notes.md). Each token's source is in the tables. ResearchRabbit paints one light theme, so this page has no dark mode.

Plus Jakarta Sans and IBM Plex Sans load from Google Fonts. Icons on this page are drawn by hand to stand in for the app's; the real ones are in the screenshots. The app writes its labels in title case ("Search Settings", "Positions Moved"); this page writes them in sentence case.

A reference implementation of the engine on one canvas, fed by the graph.* tokens: 30 machine learning concepts placed by data, not by physics. Across is the week a concept is introduced (compact: each distinct week gets one even step), up is how many concepts build on it, on a log base 4 scale, fitted into the 500 unit box and then to the screen. Arrows point from a concept to what it needs, the way the app points from a citing paper to the paper it cites.

    Hover a node or a row: neighbours stay, the rest fade to graph.interaction.recede-opacity. Click a node to inspect it; Shift-click adds to the selection. Drag a node to move it; drag empty space to box select. Space held, or the hand button: drag pans. + - zoom, with Shift a bigger step; arrows pan; F recenters. Ctrl or ⌘ with the wheel zooms to the cursor; the plain wheel pans. The app leaves its wheel handler empty; this demo attaches it.

    Where this demo departs from the engine on purpose: hit testing uses circles rather than the engine's squares, labels are ranked by dependants (the engine means to rank by citations but reads the wrong field, so every label ties), touch works as well as the mouse, and the frame loop stops when nothing moves rather than polling. Each is marked in the script.

    Elevation

    Three blue-grey shadows, each two layers. The darker set is declared beside them and painted nowhere captured.

    Motion

    Chrome moves on short transitions and one spring-like popup curve. The graph has its own timings: a 500 ms camera, 200 ms zoom steps, and random spans per node so the map never moves as one block. Press a track to run it.

    Graph tokens

    The engine's constants. A bare number is in graph units (the layout box is 500 tall) or is a factor; a px value is screen pixels, which the engine keeps constant at every zoom. Inferred values say so.
