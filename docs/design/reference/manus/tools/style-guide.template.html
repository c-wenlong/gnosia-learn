Manus, measured

Every value on this page is a CSS custom property generated from tokens.json: Manus's own two palettes (:root for light, .dark for dark, in one stylesheet), its --ui-* type and density scale, and a handful of measured layout numbers. The toggle in the header flips the dark class on <html>, which is exactly how Manus switches. Component drawings below are rebuilt from the tokens, not screenshots; the real pixels are in screenshots/ and components/crops/.

Read from manus.im/app on 2026-10-04, signed in, through static copies of each page. The system font stack is what Manus ships for UI text; the serif is Libre Baskerville (self-hosted by Manus, loaded here from Google Fonts), used for the home prompt, the wordmark, the share banner and document titles.

Colour

Manus names colours by role, not by hue: text, icon, background, border, fill (the translucent hover and chip fills, tsp for transparent), function (status), Button, tab, shadow, plus the accent palettes a user can choose in the desktop app. Each swatch shows the active theme's value; flip the header toggle to compare.

Typography

One system sans for the interface, a serif for display moments, a mono for code. The scale is Manus's --ui-font-size-* / --ui-line-height-* pairs; body-sm (14/22) is what desktop chat text and the composer use.

Density, space and shape

Manus drives spacing through its --ui-density-* variables rather than a plain spacing scale: row heights, radii, paddings and gaps that the sidebar, menus, chat and composer all read. The desktop app's Compact setting rewrites them (shown as the second value).

Elevation

Manus keeps shadows faint and leans on borders and fills: shadow.XS/S/M/L are the colours its utilities compose, the shadows-drop-* and shadows-inner-* set is a second, newer scale used by the activity indicator and cards.

Motion

Short and standard: the sidebar slides in 200 ms, resizes ease out over 300 ms with a spring-like curve, theme changes cross-fade over 500 ms. Click a track to play it.

Layout

One 300 px sidebar (52 px as a rail) and a content column. Page chrome is a 48 px bar. The task thread and composer are capped at 800 px; the Library's list at about 960 px. Phones get the same sidebar as a drawer.
